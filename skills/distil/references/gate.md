# 合取闸门与发布纪律

> 项目没有自动评分基准,不用均值闸门;接受谓词是三条合取,判官只核这三条,不打总分。蒸馏与提案可以批量跑,接受永远停在待审。

## 接受谓词(合取三条,缺一即拒)

1. **既有门禁无回归**:项目门禁集与点名义务同轮首点名(全量或快速子集),点名后不得收窄;门禁清单固定成文于 AGENTS 或 README(命令原文加退出码口径),首点名即引清单不临场抄;候选标准集下点名门禁仍绿,任何一条变红即拒;真浏览器、整树或多平台小时级编译、跨仓验收门(他方工序)等重门禁可记当轮不适用附理由,或以代理面满足(增量编译绿加产物在位自证)
2. **点名义务翻转**:至少一条事先点名(loop.md 执行步登记)、当前标准盖不住的失败义务,在候选下变为通过;仅「没有回归」是中性改动,拒;门槛是「变好」,不是「不变坏」
3. **知识链接成立**:候选标准页链到至少一页有 sources 引文的 knowledge 模式页(layers.md 单向支撑硬规则的闸门化)

- 判据形态:不看均值看点名;均值会掩盖单题回归,已翻转为过的点名义务在候选下退回缺,或任一已绿门禁变红,即拒
- 证据形态:门禁退出码自取、义务翻转自跑验证、链接自验可达,本地 hook 当场拦截属谓词 1 证据记入闸门记录段;三谓词证据全为确定性命令(退出码、复跑、链接可达)可免隔离轮,证据含 agent 行为(技能是否被正确触发、会话表现)必须按 backends.md 隔离跑;**触发用例集**:每技能 3 至 5 条查询(应触发至少一、不应触发近失至少一、含糊边界至少一),随技能入库(技能 references 目录下 evals 件(3 至 5 条,markdown 形),渐进披露第三级),候选写成后接受前那一轮跑,两方各跑(提案者自跑候选态证据、判官复核);隔离会话私有 config dir 只挂候选集,应触发与近失同会话序贯、含糊边界独立会话;fail 映射:应触发 fail 即谓词 2 不成立,不应触发 fail 即谓词 1 等价面(误触发是对既有工作流的回归),含糊 fail 即证据不足走 no_action;触发二值断言不打均值,产出质量留人裁;初测误触发收窄 description 与 When NOT to Apply 后复测至全符(判例:第四实践仓首环近失负例揭出触发面过宽,收窄复测转绿);多次采样留判例(首版单会话逐条,触发不稳定再升);不引 pass rate、均值、baseline 分差闸;单次随机会话不得当分数
- `no_action`:证据不足的合法出口,不跑闸、不改标准集、照记流水

## 回滚与留痕

- 拒绝:标准集 reset 回基线提交;提案全文加 diff 由闸门追加进防重提页(knowledge,只增);流水记一行结论
- 接受:标准集 commit(消息记轮次与翻转的义务);流水与索引同步
- knowledge 在闸门前已提交,拒绝不回收:模式仍然成立,只是这一案没有过

## 发布纪律

- **标准面只收过闸产物**:operations 层根(标准技能与 how-to 手册)里只能有接受后的标准页;技能安装路径是加载视图只链技能子集,常驻面只有 frontmatter 的 name 与 description;knowledge 页、被拒全文、no_action 记录可留可读,但不得出现在技能安装路径上,蒸馏文本不是标准 skill;本机态文件(settings.local.json 等)不入库,与标准面目录混居时以忽略登记划界
- **无人值守只批蒸馏与提案**:夜跑可以积累模式页与待审提案,接受停在人裁,不自动发布
- **记忆与技能写入边界**:agent 记忆与目标档只收偏好、进行中状态与指针;步骤形内容唯一入口是过闸,写进常驻记忆即绕闸记违规(防内容走私绕三谓词)
- 成品不点名外部仓库:标准 skill 正文自包含,信源细节留 sources 与研究档案

## 跨端转移

- 标准 SKILL.md 字节可拷(双端同形),但**转移不是发布**:拷入目标端后是未提交的一案,在目标端重过同一合取谓词(目标端门禁、目标端点名义务);失败即 reset 回转移前提交;目标端同名标准默认不覆盖,覆盖须显式裁定
- 不做「拷完立刻 commit」;不做「一端进化、另一端直接继承」:两端各自的门禁各自过
