# 轨迹总结:带时间的历史轨迹(sources 层形态)

> sources 层的标准件形态:一天一篇活轨迹,当日用户令、裁定、坑与门禁实录。轨迹是蒸馏的原料(模式页从轨迹取样),不是结论本身;结论升 knowledge,此篇只管怎么记。

## 形态

- 文件名 `YYYY-MM-DD-主题.md`,一天一篇;初始化当天记首笔
- 篇首引块记当日用户令原文与当日闭环概览,读首行即得脉络
- 正文分节:裁定(逐条编号,记档为常例,可被后续轨迹与 ADR 引用)、坑(实档,含修法与预防,不止现象)、门禁退出码(不贴全输出,记退出码与判据)、终态(当轮交付面:版本、提交、分发);存量日记旧形留档不改写,新篇起用标准四节,旧形坑与裁定仍可被点名义务回引
- 过程不改写:轨迹是历史,修正走新条目;存量禁字走路径级豁免通道,历史留痕
- 检索面:文件名即索引(日期加主题),rg 按主题词直达当日篇

## 资格与边界

- 轨迹记真实执行:会话、派单、评审、门禁各留指针(commit sha、会话文件路径、退出码);资格过滤纪律见 layers.md,零工具调用的回合不进蒸馏样本
- 与 agent memory 分工:偏好与临时约束走 memory,事实轨迹进本层
- 轨迹不替代研究:课题全程证据进研究档案(S 编号,doc-gov 形态),本层只留执行过程

## 升格分流(轨迹到知识)

- 轨迹是素材池:二犯的坑、反复的裁定,蒸馏成 knowledge 模式页(带本层引文,见 loop.md)
- 不可逆决策升 ADR、需求升 REQ(doc-gov 形态);双层裁定账:可逆与过程裁定入冻结索引账(轻量编号),不可逆才升 ADR,轻裁定不挤占 ADR 号段;升格后轨迹留档不删
- 终态节是封版与复盘的取材面:点名失败义务从这里的坑与门禁实录里抽
