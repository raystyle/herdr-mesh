## distil 蒸馏环操作指导(产出物 = 标准 hook rule 件)

- 核心思想:项目规则集是被治理的活资产。执行轨迹先落 sources(唯一出处),蒸馏成带版本双链的 knowledge,一案提案过合取闸门才进标准面(operations:标准 hook rule 件与 how-to 手册)
- 三层单向支撑:sources 撑 knowledge,knowledge 撑标准 hook rule,反向不成立;知识层永不回滚,标准层拒绝即回滚;证据不足走 no_action,不硬造产出
- 四步环:轨迹总结(sources 轨迹篇)-> 模式提炼(knowledge 模式页,双链)-> 一案提案(单件变更,create/patch/retire)-> 合取闸门(三谓词全过才提交标准面)
- 闸门判据:来源可溯(链到支撑模式页)、谓词可检(命中的实弹证据)、pattern 有效(词表每词至少命中一条真实意图样本且无误命中对照;pattern 无效即提案失败)
- create 产出 = 新标准 hook rule 件(frontmatter patterns/match + 注入正文);patch = 改既有件锚定操作;retire = 退役注记不回收
- 标准件字节可拷(双端同形)但转移不是发布:拷入目标端是未提交一案,重过同一合取谓词;失败即 reset 回转移前提交
